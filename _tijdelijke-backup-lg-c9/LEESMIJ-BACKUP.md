# Tijdelijke backup — hoort hier niet

Deze map is een veiligheidskopie van de inhoud die bedoeld is voor de aparte repo
`tkuster81/lg-c9-webos-mod`.

De reden dat hij hier staat: de sessie kon niet naar die nieuwe repo pushen omdat de
Claude GitHub App daar nog geen toegang tot had, en de container waarin het werk stond
is tijdelijk. Zonder deze kopie zou het werk verloren gaan als de sessie wordt opgeruimd.

**Zodra de inhoud in `lg-c9-webos-mod` staat, kan deze hele map weg**, samen met
`docs/lg-c9-custom-os-plan.md` (de oudere, enkele-document-versie van hetzelfde plan).
